# Gunnar's Calculator

A calculator web app in plain HTML, CSS and JavaScript, with keyboard support and input validation.

> **Status:** my first learning project (September 2025), finished and not maintained. Parts follow tutorials and examples listed under References.

## Features

- **Arithmetic:** addition, subtraction, multiplication and division.
- **Input:** parentheses, decimal numbers and math symbols (×, ÷).
- **Keyboard support:** numbers, operators, parentheses, Enter (=), Escape (clear) and Backspace.
- **Input validation:** blocks double operators and multiple decimals in one number.
- **Error handling:** shows an error for invalid expressions instead of crashing.
- **Responsive layout:** CSS Grid and Flexbox for mobile and desktop.
- **Read-only display:** input only through the buttons or validated keys.

## Project structure

- **index.html:** calculator layout with buttons and the display.
- **styles.css:** glass-style design with shadows, gradients and hover effects.
- **index.js:** calculator logic, input validation, keyboard support and error handling.

## Run it

1. Clone or download the repository.
2. Open `index.html` in any modern browser.

No build step or dependencies.

## Ideas not implemented

- Calculation history.
- Scientific functions (sin, cos, sqrt).
- Light and dark themes.
- Better screen reader support with ARIA roles.
